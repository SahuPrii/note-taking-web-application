# Note Taking Application

A simple and responsive note-taking application that allows users to create, edit, and delete notes easily.

## Tech Stack

- HTML
- CSS
- JavaScript
- React.js

## Features

- Create new notes
- Edit existing notes
- Delete notes
- Simple and responsive user interface
- Easy note management

## Project Purpose

This project was developed to practice frontend development and build a simple user-friendly note management application.
